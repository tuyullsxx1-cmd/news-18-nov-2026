# One Day • The World — Wednesday 18 November 2026

41 sourced world-news stories from Wednesday 18 November 2026 (00:00–24:00 UTC), in one 1:1 PNG image. Built with Python PIL (main.py), original drawings only.

Entry for the make.fun bounty: [Sum up 18 November's world news in one image](https://make.fun/bounty/news-image-20261118)

- Image: news-18-nov-2026.png (2048x2048, 408 KB)
- Stories + sources + date verification: SOURCES.md
- Design notes: DESIGN.md
- Build: python3 main.py

Every story was first reported on 18 Nov 2026 UTC. See DATE CHECK in the image and SOURCES.md for what was deliberately excluded (17 Nov stories and post-18 Nov stories).
