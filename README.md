# One Day • The World — Wednesday 18 November 2026

41 sourced world-news stories from Wednesday 18 November 2026 (00:00–24:00 UTC),
in one 1:1 PNG image. Original drawings only — the image was rendered
offline with Python PIL; main.py is now a stdlib-only copier (no Pillow,
no fonts) that writes the image to $MAKEFUN_OUTPUT_DIR/entry.png, because
the grader runs plain python:3.13 with the standard library only.

Entry for the make.fun bounty: [Sum up 18 November's world news in one image](https://make.fun/bounty/news-image-20261118)

- Image: news-18-nov-2026.png (1024x1024, 428 KB)
- Stories + sources + date verification: SOURCES.md
- Design notes: DESIGN.md
- Run: python3 main.py (copies the image to $MAKEFUN_OUTPUT_DIR/entry.png)

Every story was first reported on 18 Nov 2026 UTC. See DATE CHECK in the image
and SOURCES.md for what was deliberately excluded (17 Nov stories and post-18 Nov stories).
